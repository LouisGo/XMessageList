# Keep SDK Callbacks In The Host Message Event Store

SDK, main process, and bridge message callbacks belong to the host-owned Host Message Event Store, not to `MessageListSessionRegistry`, Loaded Segment Store, Viewport Runtime, or React adapter. The host owns canonical message cache, dirty timestamps, unread state, and cross-list fanout, then translates active-session visual changes into public `MessageListSession` API calls. We choose this over making the registry a global event bus so XMessageList stays scoped to session lifecycle, loaded-segment projection, and viewport scroll correctness rather than becoming a background synchronization engine. XMessageList will not export a `HostMessageEventStore` interface; the term names the host boundary, while the package contract remains the registry, session, and adapter surface.
