# 会话激活与恢复规格

本文件描述用户进入、离开、切换会话时，消息列表必须呈现的可观察交互结果。

## A1 首次进入无阅读记忆

Trigger：用户打开一个没有阅读位置记忆的会话。

Acceptance：

- 列表展示该会话的最新一段消息。
- 最新消息位于列表底部区域。
- 如果消息总高度不足一屏，消息内容贴近底部。
- 如果消息总高度超过一屏，滚动位置停在真实内容底部。
- 进入完成后，继续收到新消息时保持追底状态。

User-visible result：

- 用户看到的是最新消息上下文，不需要手动滚到底。
- 首屏不能先闪现旧消息、空白列表或错误位置再跳到底部。

Forbidden：

- 不允许用旧会话的滚动位置初始化新会话。
- 不允许先展示中间位置，再通过二次跳转回到底部。
- 不允许用空白 spacer 制造可滚动历史高度。

## A2 首次进入有阅读记忆

Trigger：用户打开一个存在阅读位置记忆的会话。

Acceptance：

- 列表以记忆中的消息作为恢复目标。
- 恢复目标可见，且位于上次记录的视觉位置附近。
- 如果记忆包含 viewport offset，例如距离视口顶部 `60px`，恢复后目标消息应保持在该 offset 附近。
- 目标消息上下必须展示连续消息上下文。
- 恢复完成前不能触发普通 before / after 翻页。

User-visible result：

- 用户回到接近上次离开的阅读位置。
- 用户不能看到列表先到底部、再跳到历史位置。

Forbidden：

- 不允许把跨会话恢复简化为复用旧 `scrollTop`。
- 不允许恢复到目标消息存在但视觉位置明显错误的状态。
- 不允许因为恢复 segment 较短就强行吸底。

## A3 阅读记忆目标不可用

Trigger：记忆中的目标消息已删除、不可访问、权限变化或无法渲染。

Acceptance：

- 列表展示与目标消息最接近且确定的 fallback 位置。
- fallback 状态必须可区分于正常恢复。
- 恢复完成后，滚动位置稳定，不再反复寻找原目标。

User-visible result：

- 用户不会看到空白列表或无限 loading。
- 用户看到的是可解释的邻近上下文或 fallback 行。

Forbidden：

- 不允许因为目标缺失而自动回到底部，除非产品显式要求。
- 不允许在缺失目标和 fallback 之间来回跳动。

## A4 Warm 会话切换

Trigger：用户在已经完成加载并保留阅读状态的会话之间切换，例如 A -> B -> A。

Acceptance：

- 切换后的会话立即展示上次稳定的消息画面。
- 列表不能白屏、闪烁、先空后填充。
- 已经稳定的会话再次切回时，不应出现居中 loading。
- 切换前后的阅读位置应保持一致或接近一致。

User-visible result：

- 用户可以连续点 A、B、A，消息列表表现为即时切换。
- 之前读到的位置不会因为切换丢失。

Forbidden：

- 不允许把 A 的消息短暂显示在 B 的会话中。
- 不允许切回 warm 会话时先展示底部，再恢复历史位置。
- 不允许在已有稳定画面时显示不必要的 loading overlay。

## A5 Cold 会话切换与延迟 Loading

Trigger：用户切换到一个尚未准备好首屏消息的会话。

Acceptance：

- 如果切换原因是定位到某条目标消息，遵循 [目标消息定位规格](./destination-jumps.md)，目标消息优先于该会话已有阅读记忆。
- 请求在 `200ms` 内完成时，不显示居中 loading overlay。
- 请求超过 `200ms` 仍未完成时，显示居中 loading overlay。
- overlay 不改变消息列表滚动高度，也不推动消息内容。
- 数据准备完成后，overlay 消失，列表一次性展示正确位置。
- 如果该会话无阅读记忆，展示 latest 底部位置。
- 如果该会话有阅读记忆，展示 around restore 位置。

User-visible result：

- 快速加载的会话不会闪一下 loading。
- 慢加载的会话有明确等待状态。
- loading 结束时不能出现可见跳动、白屏或错位。

Forbidden：

- 不允许 loading overlay 和错误会话内容同时出现。
- 不允许先显示空列表，再在数据到达后跳到目标位置。
- 不允许 overlay 参与 scrollHeight 或改变 thumb 比例。

## A6 切换期间的旧事件隔离

Trigger：用户切换会话时，旧会话仍有滚动、分页、恢复、loading 或请求结果尚未完成。

Acceptance：

- 新会话只响应属于自身的消息、loading 和滚动状态。
- 旧会话完成的请求不能改变新会话画面。
- 旧会话的边缘 loading、错误、滚动条位置不能出现在新会话。
- 快速连续切换时，最终展示的必须是最后一次选择的会话。

User-visible result：

- 用户快速点击 A、B、C 时，最终只看到 C 的正确画面。
- 不会出现 A/B/C 内容交叉、loading 残留或滚动条突然跳动。

Forbidden：

- 不允许旧会话的边缘加载结果插入当前会话。
- 不允许旧会话的滚动惯性继续驱动新会话翻页。
- 不允许旧会话的 overlay 在新会话数据完成后残留。
