# 目标消息定位规格

本文件描述用户从 pin list、mentions、收藏、搜索结果、引用消息、回复栈、媒体时间点或外部链接跳转到某条消息时，消息列表必须满足的交互验收结果。

## J1 统一定位入口

Trigger：用户点击任何能定位到目标消息的入口。

入口包括：

- pinned message / pin list。
- unread mention / mention list。
- saved / 收藏结果。
- search result。
- reply / quote 引用消息。
- media、文件、链接、日历、时间点等消息结果。
- 跨会话外部链接或全局搜索结果。

Acceptance：

- 所有入口最终都定位到一个明确目标消息或明确 fallback。
- 目标消息展示完成后必须高亮。
- 默认视觉对齐为 center：目标消息尽量位于视口中间区域。
- 如果目标靠近当前 loaded segment 的真实顶部或底部，无法完全居中时，可以贴近可达的最接近位置。
- 跳转不应通过全历史百分比滚动表达。

User-visible result：

- 不同入口的跳转手感一致。
- 用户能清楚看到跳转目标是哪条消息。

Forbidden：

- 不允许 pin、mention、搜索、引用各自表现为互相矛盾的滚动规则。
- 不允许默认把目标消息贴到视口顶部。
- 不允许跳转完成后没有任何目标高亮或目标提示。

## J2 同会话，目标已在当前可见范围

Trigger：用户在当前会话点击目标消息，且目标消息已经在当前视口内可见。

Acceptance：

- 不显示 loading。
- 不重建消息列表。
- 目标消息应高亮。
- 如果目标已经接近视口中心，可以保持当前位置并只高亮。
- 如果目标明显偏离中心，应移动到视口中心附近。

User-visible result：

- 跳转即时完成。
- 用户看到目标消息被强调，不会感到列表被重新加载。

Forbidden：

- 不允许因为目标已可见仍显示 overlay loading。
- 不允许触发 before / after loading。
- 不允许先闪到底部或顶部再回到目标消息。

## J3 同会话，目标在当前已加载数据但不在视口内

Trigger：用户在当前会话点击目标消息，目标消息不在当前视口内，但已经存在于当前 loaded segment。

Acceptance：

- 不显示 overlay loading。
- 不请求 around 重建。
- 列表直接滚动到目标消息。
- 目标消息尽量对齐到视口中心。
- 跳转完成后目标消息高亮。

User-visible result：

- 用户看到列表在当前已加载内容范围内直接移动到目标消息。
- 目标上下文来自当前 loaded segment，不出现白屏或重载感。

Forbidden：

- 不允许为了已加载目标重新请求同一段数据。
- 不允许把跳转映射成 track click 或全局百分比滚动。
- 不允许目标消息落在视口顶部作为默认结果。

## J4 同会话，目标不在当前已加载数据

Trigger：用户在当前会话点击远距离目标消息，例如从底部点击引用到最早历史消息。

Acceptance：

- 当前 loaded segment 可以被目标消息附近的新 segment 替换。
- 替换后，目标消息出现在视口中心附近。
- 目标消息上下必须展示连续上下文。
- 原先底部或原先阅读位置不需要保留在新画面中。
- 跳转完成后目标消息高亮。
- 请求在 `200ms` 内完成时，不显示居中 overlay loading。
- 请求超过 `200ms` 仍未完成时，显示居中 overlay loading。
- overlay 不改变 scrollHeight，不推动消息内容。

User-visible result：

- 用户不需要看列表逐页滚过几千条消息。
- 数据准备好后，画面直接稳定到目标消息附近。
- 慢请求有明确等待状态，快请求没有 loading 闪烁。

Forbidden：

- 不允许通过连续 before / after loading 逐页滚到远距离目标。
- 不允许保留远端旧 segment 的空白高度来模拟全历史距离。
- 不允许请求未完成前显示错误目标或半截历史段。
- 不允许 overlay 和 edge loading 同时作为同一次跳转的主要 loading。

## J5 跨会话目标跳转

Trigger：用户从会话 A 跳转到会话 B 的某条目标消息。

Acceptance：

- 最终展示会话 B。
- 目标消息优先于会话 B 已有阅读记忆。
- 会话 B 以目标消息为中心展示连续上下文。
- 目标消息高亮。
- 如果会话 B 的目标 segment 在 `200ms` 内准备完成，不显示居中 overlay loading。
- 如果超过 `200ms` 仍未准备完成，显示居中 overlay loading。
- 跳转完成后 overlay 消失，画面一次性展示正确目标位置。
- 会话 A 的滚动位置、loading、边缘状态和消息内容不能污染会话 B。

User-visible result：

- 用户从 A 点击 B 的搜索结果、收藏、mention 或引用后，直接进入 B 的目标消息附近。
- 慢跳转看到的是会话级 overlay，而不是上下边缘加载。

Forbidden：

- 不允许先展示 B 的底部，再跳到目标消息。
- 不允许先展示 A 的消息，再在 B 中闪现目标。
- 不允许跨会话目标跳转用 before / after edge loading 逐页补齐。
- 不允许先恢复会话 B 的旧阅读位置，再二次跳转到目标消息。
- 不允许旧会话请求结果覆盖新会话目标画面。

## J6 目标高亮

Trigger：任意目标消息定位完成。

Acceptance：

- 目标消息必须出现高亮或等价视觉强调。
- 高亮不改变消息高度，不推动周围消息。
- 高亮应持续足够时间让用户识别目标。
- 用户继续滚动、切换会话或触发新的定位后，高亮可以自然消失或被新目标替换。
- 如果目标消息不可用，fallback 行或相邻确定消息应承担高亮。

User-visible result：

- 用户能立即辨认“跳到的是哪条消息”。

Forbidden：

- 不允许高亮造成行高变化和阅读位置跳动。
- 不允许多个旧高亮长期残留导致目标混淆。
- 不允许目标不可用时没有任何视觉落点。

## J7 目标不可用

Trigger：目标消息已删除、不可访问、权限变化或无法渲染。

Acceptance：

- 展示确定的 fallback 位置。
- fallback 尽量位于视口中心附近。
- fallback 或相邻确定消息高亮。
- 如果完全无法确定 fallback，应展示可理解的不可访问状态。
- 当前会话和目标会话不能因此进入无限 loading。

User-visible result：

- 用户知道目标无法正常展示，但仍能看到稳定的邻近上下文或错误状态。

Forbidden：

- 不允许目标不可用时自动回到底部。
- 不允许在多个候选 fallback 之间来回跳动。
- 不允许白屏或无限 loading。

## J8 定位期间用户打断

Trigger：目标跳转尚未完成时，用户切换会话、点击另一个目标、滚动或取消当前操作。

Acceptance：

- 最后一次用户意图优先。
- 新目标完成后，只显示新目标的会话、上下文和高亮。
- 被打断的旧目标不能在稍后覆盖当前画面。
- 用户主动滚动时，可以取消尚未完成的本地移动或高亮后续动作。

User-visible result：

- 快速点击多个搜索结果或多个引用时，最终停在最后点击的目标。
- 不会出现旧目标延迟跳回来。

Forbidden：

- 不允许旧目标请求完成后抢占新目标。
- 不允许多个 overlay 或多个高亮互相叠加。
- 不允许打断后仍继续逐页加载旧目标方向。
